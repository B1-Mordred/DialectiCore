# Architecture

DialectiCore is organized around durable production stages and strict contracts.

The Increment 1 scaffold contains:

- `production-api`: FastAPI application exposing episode, production,
  transcript, status, health, and audit endpoints.
- `discussion-worker`: domain service that runs the turn-by-turn discussion
  loop.
- `voicebox-adapter`: worker role that polls submitted or running remote
  Voicebox audio jobs, updates persisted audio assets, and records QC/audit
  evidence.
- `comfyui-adapter`: worker role that polls submitted or running remote ComfyUI
  visual jobs, updates persisted visual assets, and records QC/audit evidence.
- `model gateway`: provider-neutral interface for OpenAI-compatible, Ollama,
  Anthropic-compatible, Mistral-compatible, generic HTTP, and mock providers.
- `repository`: SQLAlchemy-backed episode aggregate persistence with indexed
  production-state columns and full validated aggregate JSON.
- `web-ui`: React/Vite shell for dashboard and production monitoring.

The discussion engine never asks a single model to produce the whole episode.
Each turn is generated by the active participant's configured model client using
public context plus that participant's private memory.

The current persistence checkpoint stores the complete episode aggregate in
`episode_records.payload` while projecting `id`, `title`, `slug`, `status`,
`source_language`, timing, workflow, canonical transcript, and timestamps into
columns. Later increments can normalize high-volume artifacts such as turns,
assets, and audit events while preserving the API contract.

`project_records` stores the first-class project catalog required by the domain
model. Episode aggregates can reference `project_id`, project CRUD operations are
audited, and project deletion is blocked while linked episodes exist.

Reusable model endpoint records and participant profile records are stored
separately so producers can configure model assignment, role, perspective,
expertise, prompt template, and speaking style before creating an episode.
